# 项目规划

## 一、财务审核 Agent 项目：方向综合评价

### 核心优势

#### 1. 完美满足

1. 真实刚性痛点

   中小企业财务报销、费用审核、对公付款单据量大、规则繁琐：差旅标准、补贴限额、发票真伪、票据重复报销、超标准消费、附件缺失、预算占用、对公付款风控，全是标准化、高频、高人力成本工作。

2. 闭环完整，不是简单问答

   用户上传报销单 / 发票图片→Agent 自动识别→拆分多阶段审核任务→自动校验财务规则→异常单据推送人工复核→审核通过自动同步预算、生成凭证；全链路业务闭环，绝非一问一答聊天。

3. **效果极易量化（评估体系天然落地）**

- 效率指标：人工审核时长 vs Agent 自动审核时长、单日处理单据量

- 风控指标：重复报销拦截率、超标单据识别率、虚假发票检出率、漏审率

- 成本指标：财务人力节约、审核驳回人工沟通次数

  完全满足你「可评估效果，不靠主观感觉」的硬性要求。

#### 2. 天然适配多 Agent 协同，不存在炫技过度设计

财务审核天然分专业领域，拆分 Agent 完全贴合业务，不会强行堆多智能体：

1. **文档解析 Agent**：OCR 识别发票、报销单、行程单、合同，抽取金额、日期、商户、税号、差旅类型

2. **规则校验 Agent**：企业财务制度校验（交通住宿标准、补贴上限、报销时效、部门预算剩余）

3. **风控审计 Agent**：识别重复报销、大额异常、公私混淆、虚假票据、跨部门违规申领

4. **预算核算 Agent**：计算本次报销占用部门预算、剩余额度、月度累计支出

5. **审批调度 Agent**：统筹全流程任务拆分、失败重试、推送人工审核工单

   分工清晰、各司其职，业务逻辑边界天然隔离，完美匹配你的 Multi-Agent 设计约束。

#### 3. 人机协同、高风险人工卡点天然成立（行业强刚需）

财务属于资金敏感场景，完美契合你「人机协同、人工干预」要求：

1. 系统自动放行：小额、完全合规、材料齐全单据，Agent 自动通过
2. 强制人工复核节点（可可视化配置）：
    - 单笔大额报销、超部门预算支出
    - 发票存疑、票据缺失、超标消费
    - 对公转账、预付款、合同类费用
    - 跨部门分摊、特殊补贴申请
3. 双向人工干预：财务可驳回、修改单据金额、补充备注、直接终止任务；Agent 暂停流程生成审核工单，全程留痕审计。

#### 4. 上下文、知识库需求充足，支撑上下文工程模块

1. 全局知识库：企业财务制度库、差旅标准、各部门预算规则、税收政策、票据规范（向量库存储 RAG 检索）

2. 用户长期上下文：员工职级、所属部门、月度已报销额度、历史违规记录

3. 任务上下文：单次报销全套票据、每一步校验结果、异常记录、人工审核意见

4. 会话上下文：员工与财务沟通记录，长单据自动摘要压缩，解决 Token 超限

   完全能落地分层上下文隔离、自动压缩、租户隔离逻辑。

#### 5. 可观测 & 评估体系落地成本极低，指标天然齐全

- 性能维度：单据处理耗时、OCR 耗时、规则校验耗时、MQ 队列堆积

- 成本维度：OCR 调用费用、大模型 Token 消耗、向量检索调用量

- 质量维度：单据识别准确率、规则校验正确率、风险漏判率、人工复核率

- 故障维度：图片模糊识别失败、接口超时、预算查询异常、MQ 消息丢失

  所有指标均可做前端监控大盘，完美满足可观测要求。

#### 6. 安全风控标准高度贴合财务场景（加分项）

1. 数据脱敏：身份证、银行卡、企业税号、工资金额自动脱敏展示
2. 权限隔离：多租户隔离（多公司财务数据完全隔离）、员工仅可见自己单据，财务管理员可见全部门单据
3. 调用安全：禁止越权查询其他部门预算、禁止批量导出全公司财务数据
4. 输入风控：拦截篡改票据金额、恶意绕过财务规则的 Prompt 注入

#### 7. 工程层面适配你的分布式微服务技术栈

- 高频单据处理并发：RabbitMQ 异步削峰，处理上传单据任务

- 预算、单据数据持久化 MySQL；Redis 缓存部门预算、临时单据上下文、分布式限流

- Nacos 配置动态更新财务规则（差旅标准不用改代码，后台配置生效）

- Milvus 向量库存财务制度、政策文档，RAG 辅助复杂规则解读

- MinIO 存储发票、报销单图片附件

  整套中间件全部复用你本地现有环境，无额外部署成本。

### 二、该方向唯一潜在短板 & 配套解决方案（提前规避）

#### 短板 1：OCR 依赖第三方 API，存在外部依赖故障

解决方案：

1. 封装统一 OCR 工具 Starter，支持多厂商兜底（百度 / 阿里 / 本地轻量 OCR）；
2. 工具熔断降级，OCR 识别失败自动重试 3 次，模糊图片直接推送人工录入；
3. OCR 调用用量、成本纳入监控指标。

#### 短板 2：财务规则复杂，规则变更频繁

解决方案：

1. 后台可视化配置财务审核规则（差旅标准、限额、时效），存储 Nacos 动态刷新，无需发布服务；
2. 规则变更记录日志，支持审计追溯；
3. 规则校验 Agent 自动加载最新规则，无需重启服务。

#### 短板 3：多租户企业财务数据隔离要求极高

解决方案：

数据库设计采用**租户 ID 逻辑隔离**，所有单据、预算、知识库表强制携带 tenant_id，SQL 统一拦截加租户条件，杜绝跨租户数据泄露，满足企业财务合规要求。

## 二、财务审核 Agent 完整业务流程（端到端闭环，写进项目需求文档）

1. **单据提交**：员工前端上传发票、报销单图片，填写基础报销信息，提交任务

2. **任务分发**：网关接收请求，RabbitMQ 异步分发至 Agent 调度服务

3. 多 Agent 协同自动审核

   ① 文档解析 Agent：OCR 提取票据全部信息，校验图片清晰度，识别失败直接进入人工

   ② 预算核算 Agent：查询该员工部门当月剩余预算，核算本次报销占用额度

   ③ 规则校验 Agent：匹配企业财务制度，判断住宿 / 交通是否超标、是否超报销期限

   ④ 风控审计 Agent：检索历史单据，判断是否重复报销、识别大额异常消费

4. 结果分支处理

    - 全合规小额单据：Agent 自动审核通过，更新预算，生成审核记录，通知员工
    - 存在异常 / 大额单据：任务暂停，生成人工审核工单推送财务人员

5. 人机协同审核

   财务人员查看单据、Agent 校验异常点，可：通过 / 驳回 / 修改金额 / 补充备注

6. 流程收尾

   审核完成后同步单据状态、预算数据，所有操作日志、Agent 执行记录持久化归档，支持审计查询

## 三、补充进原需求文档的专属业务说明（可直接复制）

### 业务定位：多租户企业财务智能审核 Agent 平台

#### 目标用户

1. 企业员工：提交报销单据，查看审核进度
2. 企业财务人员：人工复核异常单据、配置财务审核规则、查看审核统计报表
3. 企业管理员：租户管理、权限配置、查看全公司财务风控大盘

#### 核心解决痛点

1. 人工审核单据效率低，大量标准化单据占用财务人力
2. 财务规则复杂，人工容易漏审超标、重复报销等风险单据
3. 财务数据分散，无法直观统计报销、预算、风控数据
4. 资金操作风险高，缺少标准化前置风控拦截机制

#### 核心业务价值

1. 降低财务 70% 标准化单据审核工作量
2. 前置拦截报销风险，减少企业资金损失
3. 自动化预算核算，实时管控部门支出
4. 全流程留痕，满足财务审计合规要求

## 四、微调建议

1. 微服务无需新增，原有拆分完全适配：
    - rag-service：存储财务制度、税收政策知识库
    - tool-service：统一封装 OCR 工具、预算查询工具、票据校验工具
    - agent-core-service：承载 5 类财务专用 Agent 调度编排
2. 前端页面新增专属财务模块：报销单据上传页、财务审核工单页、预算配置页、财务规则配置页、风控审计报表；
3. 评估体系新增财务专属指标：票据识别准确率、风险单据拦截率、人工复核占比、预算超支预警次数；
4. 人机协同模块强化资金审批工单，单独配置资金类操作多级人工审核开关。
