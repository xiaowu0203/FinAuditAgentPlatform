## 3. 接口对接（全部经网关 9080）

网关**不剥前缀**，下游 Controller 映射 `/api/v1/...`（已核对 `AuthGlobalFilter` 路由表与各 Controller `@RequestMapping`）。前端 axios baseURL = `/api/v1`，Vite dev 代理 `/api` → `http://localhost:9080`，开发期避免 CORS 且不硬编码网关地址。

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| POST | `/api/v1/auth/login` | 登录（白名单） | 无 |
| POST | `/api/v1/auth/logout` | 登出（网关注入 `X-Jwt-Jti`） | Bearer |
| GET | `/api/v1/auth/me` | 当前用户 | Bearer |
| POST | `/api/v1/tasks` | 提交任务 | Bearer |
| GET | `/api/v1/tasks` | 分页（`pageNum`/`pageSize`/`status`） | Bearer |
| GET | `/api/v1/tasks/{id}` | 任务详情 | Bearer |
| GET | `/api/v1/tasks/{id}/steps` | 步骤明细 | Bearer |
| POST | `/api/v1/tasks/{id}/resume` | 断点续跑 | Bearer |

统一响应：`{ code, message, data }`，`code === 0` 成功；登录响应 `data.token` + `data.user`。

axios 拦截器约定：
- **请求**：自动注入 `Authorization: Bearer <token>`
- **响应**：HTTP 401 → 清本地 token → 跳登录页（登出/被踢/过期自动处理）；`code !== 0` → `ElMessage.error(message)`

任务状态机：`PENDING → RUNNING → SUCCESS / FAILED`（步骤 FAILED 且 retryCount<3 自动重试）。列表与详情在 `PENDING/RUNNING` 时轮询刷新。

## 6. 验收清单（P1 完成定义）

1. 登录 → 提交任务 → 轮询至 SUCCESS → 详情见步骤与结果
2. 步骤失败任务 → FAILED → 详情见 errorMsg。**续跑仅对 PENDING/RUNNING 有效**（后端契约：SUCCESS/FAILED 返回 400「任务已终结，无需续跑」，FAILED 重跑留待后续版本）
3. 登出 → 旧 token 请求 401 → 前端自动跳登录（会话作废闭环）
4. 跨租户隔离：租户2（`acme`）登录 → 列表看不到租户1 任务
5. 刷新页面 token 保持（localStorage）
6. 后端不可达时前端有明确错误提示（非白屏）
